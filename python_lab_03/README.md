
# SleepTracker

Лабораторная работа №3 по дисциплине «Теория алгоритмов».

**Тема:** Работа с графическим интерфейсом на Python  
**Вариант:** Приложение для отслеживания сна  
**Сложность:** Well-done

## Описание

SleepTracker — приложение для учёта и анализа продолжительности и качества сна.

Реализованы две версии: настольная на PyQt6 и веб-версия на FastAPI. Обе работают с единой базой данных PostgreSQL.

## Возможности

- Добавление, редактирование и удаление записей о сне
- Указание времени засыпания и пробуждения, качества сна и комментария
- Автоматический расчёт продолжительности сна
- Расчёт средней, минимальной и максимальной продолжительности
- Построение графика продолжительности сна по дням
- Ведение истории действий
- Проверка корректности данных и пересечения интервалов сна

## Технологии

- Python, ООП
- PyQt6 и Qt Designer
- FastAPI
- HTML, CSS, JavaScript, Chart.js
- Matplotlib
- PostgreSQL, Docker
- pytest

## Структура проекта

- `sleeptracker/domain/` — модели данных, статистика и исключения
- `sleeptracker/database/` — подключение к PostgreSQL и репозитории
- `sleeptracker/api/` — HTTP API на FastAPI
- `sleeptracker/desktop/` — настольный интерфейс PyQt6
- `sleeptracker/web/` — веб-интерфейс
- `tests/` — автоматические тесты

## Запуск

Все команды выполняются из каталога `python_lab_03`.

### 1. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 2. Настройка базы данных

Создать `.env` на основе `.env.example` и указать пароль PostgreSQL.

Запустить Docker Desktop, затем выполнить:

```powershell
docker compose up -d
python -m sleeptracker.database.schema
```

### 3. Запуск FastAPI

```powershell
python -m uvicorn sleeptracker.api.main:app --reload
```

Веб-интерфейс: http://127.0.0.1:8000/web/

Документация API: http://127.0.0.1:8000/docs

### 4. Запуск настольного приложения

В отдельном терминале:

```powershell
python -m sleeptracker.desktop.main
```

Для работы настольной версии FastAPI и PostgreSQL должны быть запущены.

## Тестирование

Тестирование выполнено с использованием pytest.

```powershell
python -m pytest -v
```

Интеграционные тесты используют отдельную базу данных `sleeptracker_test`.

## Краткая справка

Пользователь указывает дату и время засыпания и пробуждения, оценивает качество сна от 1 до 5 и при необходимости добавляет комментарий.

Приложение вычисляет продолжительность сна, отображает статистику и график, а также сохраняет историю создания, изменения и удаления записей.

При попытке сохранить пересекающиеся интервалы сна приложение возвращает ошибку.

Данные хранятся в PostgreSQL. Взаимодействие настольного и веб-интерфейсов с базой выполняется через FastAPI.
